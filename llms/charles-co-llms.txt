# Charles (charlesAI)

> Berlin-based conversational commerce and CRM platform that lets brands sell, market, and support customers over WhatsApp, Instagram, Facebook Messenger, and Webchat. Charles connects chat-app APIs with e-commerce and CRM systems (Shopify, Salesforce, SAP, HubSpot) and layers AI agents over them. It exposes a token-authenticated HTTP API organized around per-tenant "universe" hosts plus a central api.hello-charles.com service, a public Postman workspace, and a (deprecated) JavaScript/TypeScript browser SDK on npm.

## API
- [Charles API reference (browser SDK docs)](https://c-commerce.github.io/charles-browser-sdk/): TypeScript SDK documentation covering auth, universe configuration, and resources.
- [API host](https://api.hello-charles.com): central API service (bearer-token authenticated).
- [Postman workspace](https://www.postman.com/hello-charles/workspace/charles/): public Postman workspace for the Charles API.

## SDKs
